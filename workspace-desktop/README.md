# Kommandr Workspace for Mac

Your own little team, at home on your Mac.

**[Download Kommandr](https://kommandr.com/download)** — Apple Silicon and Intel, macOS 13 or later.

The app checks for updates automatically. Open **Kommandr → Check for Updates** to view the available version, read what changed, and download it. Choose **Restart & update** whenever you’re ready.

[Release notes](./CHANGELOG.md)

This download is the hosted workspace app (`com.kommandr.desktop`). Its updates are separate from the earlier developer app (`com.kommandr.app`). If you installed the initial 0.1.0 preview, install this download once to enable the public update feed. Your workspace and sign-in are preserved.

Builds are Developer ID signed and Apple notarized. Each release includes DMGs, ZIPs for the updater, blockmaps, and SHA256 checksums. Application source and signing credentials are not published.
