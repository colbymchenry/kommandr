# Kommandr

One board for you and your AI coding agents. Manage projects, issues, epics, and sprints from your Mac, and keep up from your iPhone or iPad.

**[Download Kommandr](https://kommandr.com/download)** · [Account and membership](https://kommandr.com/account) · [Release notes](./CHANGELOG.md) · [All releases](https://github.com/colbymchenry/kommandr/releases)

Desktop installers are Developer ID signed and notarized by Apple. Installed apps check [`desktop/latest-mac.yml`](./desktop/latest-mac.yml) for updates. Desktop releases are tagged `desktop-vX.Y.Z`, and each one ships its checksums as `SHA256SUMS`.

The iOS companion uses the original `com.kommandr` Apple app and is available through TestFlight.

This repository holds public downloads, release notes and the update feed. The app is built from a private source repository; no source code or signing credentials are included here.
